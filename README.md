# Snake

A classic grid-based Snake game built with HTML5 Canvas and vanilla JavaScript.

## Play

Open `index.html` in a modern browser. Use the arrow keys or WASD to steer, and
press Space to pause. On touch screens, use the on-screen direction pad.

Eat the glowing food to grow and increase your score. Avoid the canvas edges and
your own tail. The snake moves continuously and gradually speeds up as you
collect food.
